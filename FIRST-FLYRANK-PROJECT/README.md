# FlyRank First Project

## Purpose

This simple project verifies that my Node.js development environment is set up
and working correctly. It was created as part of my FlyRank internship
assignment.

## Technology Stack

- JavaScript
- Node.js

## Prerequisites

Install [Node.js](https://nodejs.org/) before running the project. To confirm it
is installed, open a terminal and run:

```bash
node --version
```

If Node.js is available, the terminal will display its version number.

## How to Run

1. Open a terminal in the project directory.
2. Run:

```bash
node index.js
```

The terminal should print: `My FlyRank development environment is working.`
